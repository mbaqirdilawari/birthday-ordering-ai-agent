# Data

Everything in `simulated/` is **fake**. It is generated by `scripts/simulate_data.py` with a fixed random seed, and it is not real company data.

| File | Used by | Contents |
|---|---|---|
| `products.csv`, `bundles.csv` | Agent | Generic ice cream products and party bundles with simulated prices |
| `areas.csv` | Agent | Public neighbourhood names of Karachi with approximate coordinates |
| `distributors.csv`, `trikes.csv`, `stock.csv` | Agent | Invented distributors, their event trikes and stock |
| `master_catalog.csv` | Listing checker | Official products, names, prices, photos and status (active or discontinued) |
| `chain_accounts.csv` | Listing checker | Invented chain stores, city, branches, sales and whether they are on the platform |
| `platform_listings.csv` | Listing checker | Each account's online listings, with deliberate problems to detect |
